k-means法とは？

作成日: 2026-07-25

カテゴリ: statistics

元の質問

k-means法とは？

回答

k-means法（k平均法）は、正解ラベルのないデータを、特徴の近い \(k\) 個のクラスタへ分ける代表的な教師なし学習の手法です。各クラスタを所属点の平均である重心によって表し、「最も近い重心への割り当て」と「重心の再計算」を交互に繰り返します。MacQueenが1967年に発表した論文で、k-meansという名称と逐次的な更新法が示されました。[1]

何を最小にしているのか

\(n\) 個のデータ点を \(x_1,\ldots,x_n\)、データ点 \(x_i\) が属するクラスタを \(c_i\)、クラスタ \(j\) の重心を \(\mu_j\) とします。k-means法は、次のクラスタ内平方和を小さくする分割を探します。[2]

\[ J = \sum_{i=1}^{n} \left\lVert x_i - \mu_{c_i} \right\rVert_2^2 \]

各データ点から所属クラスタの重心までのユークリッド距離を二乗し、すべて足した量です。したがってk-means法でいう「似ている」は、基本的に特徴量空間でユークリッド距離が近いことを意味します。目的関数の値はinertiaとも呼ばれ、小さいほどクラスタ内の点が重心の近くにまとまっています。[2]

計算の流れ

  1. クラスタ数を決める: 分けたい数 \(k\) を指定する。
  2. 初期化する: \(k\) 個の初期重心を置く。
  3. 割り当てる: 各データ点を、ユークリッド距離が最も小さい重心のクラスタへ割り当てる。
  4. 更新する: 各クラスタに割り当てられた点の平均を取り、新しい重心にする。
  5. 反復する: 割り当てや重心がほとんど変わらなくなるまで、手順3と4を繰り返す。

割り当てを固定すれば平均が平方和を最小にし、重心を固定すれば最も近い重心への割り当てが平方和を最小にします。そのため、2つの操作を交互に行うたびに目的関数は増加しません。ただし、到達する解は初期重心に依存し、大域的な最小値ではなく局所的な最小値になることがあります。公式文書でも、異なる初期値による複数回の実行やk-means++による初期化が案内されています。[2]

簡単な例

2次元の点 \((1,1)\)、\((1,2)\)、\((8,8)\)、\((9,8)\) を \(k=2\) で分けるとします。適切な初期値から始めれば、前半2点と後半2点に分かれ、重心はそれぞれ \((1,1.5)\) と \((8.5,8)\) になります。近い点同士をまとめ、その集団を平均点で代表させる、という直感に対応します。

Pythonでの最小例

from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

data = [
    [1.0, 1.0],
    [1.0, 2.0],
    [8.0, 8.0],
    [9.0, 8.0],
]

scaled = StandardScaler().fit_transform(data)
model = KMeans(n_clusters=2, n_init=10, random_state=42)
labels = model.fit_predict(scaled)

print(labels)
print(model.cluster_centers_)

labels の0や1はクラスタの識別番号にすぎず、大小や優劣の意味はありません。実行や初期値が変わると、同じ分割でも番号が入れ替わることがあります。random_state は結果を再現しやすくし、n_init=10 は異なる初期値から10回試して、目的関数が最も小さい結果を選びます。

前処理が重要な理由

k-means法は距離に基づくため、特徴量の単位と尺度が結果へ直接影響します。例えば「年齢」と「年収」を生の数値のまま使うと、数値の桁が大きい年収が距離を支配しやすくなります。平均を0、分散を1にそろえる標準化は代表的な対処ですが、外れ値に敏感であり、常に自動的に適切になるわけではありません。変数の意味に応じて、標準化、変換、外れ値処理、特徴量選択を検討します。[3]

得意な場合と苦手な場合

比較 データの特徴 理由
得意 丸くまとまり、広がりが近いクラスタ 重心からの二乗ユークリッド距離で表しやすい
苦手 細長い、曲がった、入れ子状のクラスタ 重心からの距離だけでは形を捉えにくい
苦手 密度、分散、点数が大きく異なるクラスタ 平方和を下げる分割と、期待する集団が一致しないことがある
苦手 外れ値を含むデータ 平均と二乗距離が外れ値に引かれる

公式の比較例でも、異方的な分布、分散が異なる集団、サイズが不均衡な集団では、直感に反する分割が起こり得ることが示されています。[4] ノイズを含む任意形状の集団ならDBSCAN、階層構造を見たいなら階層的クラスタリング、楕円形の分布や所属確率を扱いたいなら混合ガウスモデルなど、目的に応じて別手法も検討します。

クラスタ数 \(k\) はどう決めるか

唯一の正解が自動的に決まるとは限りません。よく使われる判断材料は次のとおりです。

  • 業務・科学的な意味: 分けたクラスタを説明し、利用できる数か。
  • エルボー法: \(k\) を増やしたとき、クラスタ内平方和の改善が急に緩やかになる折れ曲がりを見る。
  • シルエット係数: 同じクラスタ内での近さと、最も近い別クラスタからの離れ具合を比較する。値は \(-1\) から \(1\) の範囲で、高いほど分離が明瞭であることを示す。[5]
  • 安定性: 初期値や標本を変えても似た分割になるかを確認する。

inertiaは \(k\) を増やせば原則として小さくなり、\(k=n\) なら0にできます。そのため、inertiaが最小になる \(k\) をそのまま選ぶことはできません。指標だけでなく、分析目的とクラスタの解釈可能性を合わせて判断します。

分類との違い

教師ありの分類は、既知の正解ラベルを学習して新しいデータのラベルを予測します。k-means法は正解ラベルを使わず、入力データ内の距離構造からグループを作ります。したがって、得られたクラスタが現実の既知カテゴリと一致する保証はなく、クラスタへ意味のある名前を付ける作業は分析者側に残ります。

まとめ

k-means法は、データを \(k\) 個に分け、各点と所属クラスタの重心との二乗ユークリッド距離の合計を小さくする手法です。高速で理解しやすい一方、\(k\) の指定、初期値依存、尺度、外れ値、クラスタ形状に注意が必要です。実際に使うときは、特徴量の尺度を確認し、複数の初期値を試し、複数の \(k\) とクラスタの解釈を比較するところまでを一連の分析として扱います。
