k-means法とは？

作成日: 2026-07-25

更新日: 2026-07-25

カテゴリ: statistics

元の質問

k-means法とは？

回答

k-means法（k平均法）は、正解ラベルのないデータを、特徴の近い \(k\) 個のクラスタへ分ける代表的な教師なし学習の手法です。各クラスタを所属点の平均である重心によって表し、「最も近い重心への割り当て」と「重心の再計算」を交互に繰り返します。MacQueenが1967年に発表した論文で、k-meansという名称と逐次的な更新法が示されました。[1]

まず全体像をつかむ

実際の分析は、次の順序で進みます。最初は「近い点をまとめ、各集団を平均点で代表させる処理」と捉えれば十分です。

  1. データを用意する: 1行を1個のデータ点、1列を1個の特徴量として並べる。
  2. 尺度をそろえる: 必要に応じて各列を標準化し、特定の列だけが距離を支配するのを防ぐ。
  3. 条件を決める: クラスタ数 \(k\)、初期化方法、試行回数などを指定する。
  4. 割り当てと更新を繰り返す: 各点を最寄りの重心へ割り当て、所属点の平均へ重心を移動する。
  5. 結果を確認する: 各点のクラスタ番号、重心、目的関数、反復回数を調べる。

4点だけの例

2次元の点 \((1,1)\)、\((1,2)\)、\((8,8)\)、\((9,8)\) を \(k=2\) で分けるとします。適切な初期値から始めれば、前半2点と後半2点に分かれ、重心はそれぞれ \((1,1.5)\) と \((8.5,8)\) になります。これが「近い点同士をまとめ、集団を平均点で代表させる」という全体像です。

仕組みを詳しく見る

1. 近さはユークリッド距離で測る

ユークリッド距離は、座標空間における2点間の直線距離です。\(p\) 個の特徴量を持つ2点を \(x=(x_1,\ldots,x_p)\)、\(y=(y_1,\ldots,y_p)\) とすると、ユークリッド距離 \(d_{\mathrm{E} }\) は次のように定義されます。

\[ d_{\mathrm{E} }(x,y) = \left\lVert x-y \right\rVert_2 = \sqrt{ \sum_{r=1}^{p} (x_r-y_r)^2 } \]

各特徴量について「2点の差を二乗する、すべて足す、平方根を取る」という計算です。例えば \(x=(1,2)\)、\(y=(4,6)\) なら、距離は \(\sqrt{(1-4)^2+(2-6)^2}=5\) です。

各座標の差をそのまま使うため、単位や数値幅が異なる特徴量を混ぜると、数値幅の大きい特徴量が距離を支配します。この問題への対処が、後述する標準化です。距離尺度そのものの違いは、関連記事「代表的なベクトル間距離は何を意味する？」でも整理しています。

2. 目的関数 \(J\) を小さくする

\(n\) 個のデータ点を \(x_1,\ldots,x_n\)、データ点 \(x_i\) が属するクラスタを \(c_i\)、クラスタ \(j\) の重心を \(\mu_j\) とします。k-means法では、最小化したい目的関数を \(J\) と書きます。\(J\) は、各点と所属クラスタの重心との二乗距離を合計したクラスタ内平方和です。[2]

\[ J = \sum_{i=1}^{n} \left\lVert x_i - \mu_{c_i} \right\rVert_2^2 \]

k-means法は、この \(J\) を小さくする分割を探します。scikit-learnでは目的関数の値をinertiaと呼びます。小さいほど、各クラスタ内の点が重心の近くにまとまっています。ユークリッド距離の二乗を使うため、大きなずれや外れ値の影響は強くなります。[2]

3. 割り当てと重心更新を交互に行う

  1. \(k\) 個の初期重心を置く。
  2. 各データ点を、最も近い重心のクラスタへ割り当てる。
  3. 各クラスタの所属点の平均を計算し、新しい重心にする。
  4. 割り当てや重心がほとんど変わらなくなるまで、手順2と3を繰り返す。

各データ点がどのクラスタに属するかを固定した場合、各クラスタの重心を所属点の平均に置くと平方和が最小になります。反対に、重心位置を固定した場合、各点を最も近い重心へ割り当てると平方和が最小になります。したがって、2つの操作を交互に繰り返すと、目的関数の値は同じか小さくなり、増えることはありません。

ただし、到達する解は初期重心に依存し、大域的な最小値ではなく局所的な最小値になることがあります。そのため、k-means++で初期化し、異なる初期値から複数回実行して結果を比較します。[2]

Python例を実行順に読む

コード全体

from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

data = [
    [1.0, 1.0],
    [1.0, 2.0],
    [8.0, 8.0],
    [9.0, 8.0],
]

scaler = StandardScaler()
scaled = scaler.fit_transform(data)

model = KMeans(n_clusters=2, n_init=10, random_state=42)
labels = model.fit_predict(scaled)

print(labels)
print(model.cluster_centers_)
print(model.inertia_)
print(model.n_iter_)

1. 入力データを行と列で読む

data は4行2列です。4行は4個のデータ点、2列は各点を表す2個の特徴量です。k-means法は、この2列を座標軸とする空間で点同士の距離を測ります。

2. StandardScaler で列の尺度をそろえる

fit_transform(data) は、各列を独立に処理します。まず fit が平均、分散、標準偏差を計算して記憶し、次に transform が各値から同じ列の平均を引き、標準偏差で割ります。[3]

各行を \(i\)、各列を \(r\)、列 \(r\) の平均を \(\bar{x}_r\)、標準偏差を \(s_r\) とすると、元の値 \(x_{ir}\) は次の標準得点 \(z_{ir}\) に変換されます。

\[ z_{ir} = \frac{x_{ir}-\bar{x}_r}{s_r} \]

統計量 第1列 第2列
平均 mean_ 4.75 4.75
分散 var_ 14.1875 10.6875
標準偏差 scale_ 約3.7666 約3.2692

StandardScaler の分散は numpy.std(..., ddof=0) 相当で計算されます。例えば先頭行 \([1.0,1.0]\) は、第1列が \((1.0-4.75)/3.7666\)、第2列が \((1.0-4.75)/3.2692\) なので、約 \([-0.9956,-1.1471]\) になります。[3]

[
    [-0.9956, -1.1471],
    [-0.9956, -0.8412],
    [ 0.8628,  0.9941],
    [ 1.1283,  0.9941],
]

変換後は各列の平均が0、分散が1になります。新しいデータにも同じ基準を使う場合は scaler.transform(new_data) とします。新しいデータに再び fit_transform を使うと、平均と標準偏差が再計算され、異なる座標系になるため注意が必要です。

3. KMeans の計算条件を設定する

model = KMeans(...) は、クラスタリングをまだ実行せず、計算条件を持つオブジェクトを作ります。Notebook上で model の内容を表示すると現れる「Parameters」は、学習結果ではなくこの計算条件です。

パラメータ 表示値 意味
n_clusters 2 作るクラスタと重心の数。
n_init 10 異なる初期重心から10回実行し、inertiaが最小の結果を採用する。
random_state 42 乱数を固定し、結果を再現しやすくする。
init 'k-means++' 初期重心が互いに離れやすくなるように選ぶ。
max_iter 300 1回の実行で許す最大反復回数。
tol 0.0001 重心の変化が十分小さいと判定する収束許容値。
verbose 0 計算途中の詳しいログを表示しない。
copy_x True 入力データを変更せず、コピーを使う。
algorithm 'lloyd' 標準的なLloyd法を使う。

各パラメータの定義と既定値は、scikit-learnの KMeans APIに定められています。[4] 設定だけを辞書で確認する場合は model.get_params() を使います。

4. fit_predict で学習し、結果を読む

model.fit_predict(scaled) は、標準化済みデータで重心を学習し、各点のクラスタ番号を返します。学習後の結果は、末尾にアンダースコアが付く属性で確認します。[4]

学習後の属性 意味
model.labels_ 各点のクラスタ番号。変数 labels と同じ内容。
model.cluster_centers_ 標準化後の特徴量空間における各クラスタの重心。
model.inertia_ 二乗距離の合計。目的関数 \(J\) に対応する。
model.n_iter_ 採用された実行が収束までに行った反復回数。

labels の0や1は識別番号にすぎず、大小や優劣の意味はありません。同じ分割でも、初期値によって番号が入れ替わることがあります。つまり、model のParametersは「どの条件で計算したか」、末尾が _ の属性は「計算して何が得られたか」を表します。

使うときに判断すること

標準化と外れ値を確認する

k-means法は距離に基づくため、特徴量の単位と尺度が結果へ直接影響します。例えば年齢と年収を生の値で使うと、数値の桁が大きい年収が距離を支配しやすくなります。標準化は代表的な対処ですが、StandardScaler 自体も外れ値に敏感です。変数の意味に応じて、標準化、変換、外れ値処理、特徴量選択を検討します。[3]

データの形がk-means向きか確認する

比較 データの特徴 理由
得意 丸くまとまり、広がりが近いクラスタ 重心からの二乗距離で表しやすい。
苦手 細長い、曲がった、入れ子状のクラスタ 重心からの距離だけでは形を捉えにくい。
苦手 密度、分散、点数が大きく異なるクラスタ 平方和を下げる分割と期待する集団が一致しにくい。
苦手 外れ値を含むデータ 平均と二乗距離が外れ値に引かれる。

公式の比較例でも、異方的な分布、分散が異なる集団、サイズが不均衡な集団では、直感に反する分割が起こり得ることが示されています。[5] 任意形状の集団ならDBSCAN、階層構造なら階層的クラスタリング、楕円形の分布や所属確率なら混合ガウスモデルなども候補になります。

クラスタ数 \(k\) を比較する

唯一の正解が自動的に決まるとは限りません。次の判断材料を組み合わせます。

  • 業務・科学的な意味: 分けたクラスタを説明し、利用できる数か。
  • エルボー法: \(k\) を増やしたとき、クラスタ内平方和の改善が急に緩やかになる折れ曲がりを見る。
  • シルエット係数: クラスタ内での近さと、最も近い別クラスタからの離れ具合を比較する。値は \(-1\) から \(1\) の範囲で、高いほど分離が明瞭であることを示す。[6]
  • 安定性: 初期値や標本を変えても似た分割になるかを確認する。

inertiaは \(k\) を増やせば原則として小さくなり、\(k=n\) なら0にできます。そのため、inertiaが最小になる \(k\) をそのまま選ぶのではなく、分析目的と解釈可能性も合わせて判断します。

教師ありの分類と混同しない

教師ありの分類は、既知の正解ラベルを学習して新しいデータのラベルを予測します。k-means法は正解ラベルを使わず、入力データ内の距離構造からグループを作ります。得られたクラスタが現実の既知カテゴリと一致する保証はなく、クラスタへ意味のある名前を付ける作業は分析者側に残ります。

まとめ

k-means法は、尺度を確認したデータを用意し、\(k\) と初期条件を決め、最寄りの重心への割り当てと重心更新を繰り返し、目的関数 \(J\) を小さくする手法です。Pythonコードも、data、StandardScaler、KMeans、fit_predict、学習後の属性という順で読むと、全体の流れと細部を分けて理解できます。
