ガウス過程回帰とは？

作成日: 2026-11-12

カテゴリ: statistics

元の質問

ガウス過程回帰とは？

回答

ガウス過程回帰（Gaussian Process Regression、GPR）は、未知の関数そのものに確率分布を置き、観測データを使って予測値と予測の不確かさを同時に求めるベイズ回帰です。関数を有限個の係数で決める代わりに、入力点どうしの似近さを表すカーネルから、あり得る関数の集まりを定めます。[1]

要点

  • 観測点の近くではデータに沿い、観測点から離れるほど通常は予測の不確かさが大きくなります。
  • カーネルが「どれくらい滑らかか」「周期性があるか」など、関数についての仮定を表します。
  • 標準的な実装は学習時にデータ数 \(n\) に対しておおむね \(O(n^3)\) の計算を要するため、少量から中規模のデータに向きます。[1]

「関数に確率分布を置く」とは

ガウス過程は、任意に選んだ有限個の入力点における関数値が、多変量正規分布に従う確率過程です。平均関数 \(m(x)\) と共分散関数、すなわちカーネル \(k(x,x')\) を使って次のように表します。[1]

\[ f(x) \sim \mathcal{GP}\!\left(m(x), k(x,x')\right). \tag{1} \]

式 (1) の \(f(x)\) は未知の関数、\(m(x)\) はデータを見る前に想定する平均、\(k(x,x')\) は入力 \(x\) と \(x'\) における関数値がどれだけ一緒に変動しやすいかを表します。平均関数は簡単のため 0 と置く場合が多く、関数の形についての仮定は主にカーネルが担います。

カーネルが「似た入力は似た出力」を数値化する

代表例は RBF カーネル（平方指数カーネル）です。

\[ k(x,x') = \sigma_f^2 \exp\!\left(-\frac{\lVert x-x' \rVert^2}{2\ell^2}\right). \tag{2} \]

式 (2) の \(\sigma_f^2\) は関数の変動幅、\(\ell\) は長さ尺度です。長さ尺度が大きいほど離れた入力どうしも似ているとみなし、ゆっくり変化する関数を想定します。RBF カーネルは非常に滑らかな関数を仮定します。粗い変化を許す Matérn カーネルや、周期性を表すカーネルなども選べます。[1][2]

観測データから予測分布を求める

入力 \(x_i\) に対する観測値を \(y_i=f(x_i)+\varepsilon_i\)、観測誤差を \(\varepsilon_i\sim\mathcal{N}(0,\sigma_n^2)\) とします。学習入力間のカーネル行列を \(K\)、新しい入力 \(x_*\) と学習入力の共分散ベクトルを \(k_*\) とすると、ゼロ平均ガウス過程の予測分布は正規分布になります。[1]

\[ \begin{aligned} \mu_* &= k_*^{\mathsf{T} } \left(K+\sigma_n^2 I\right)^{-1}y, \\ \sigma_*^2 &= k(x_*,x_*)- k_*^{\mathsf{T} } \left(K+\sigma_n^2 I\right)^{-1}k_*. \end{aligned} \tag{3} \]

式 (3) の \(\mu_*\) が予測平均、\(\sigma_*^2\) が潜在関数 \(f(x_*)\) の予測分散です。新しい観測値そのものの分散が必要なら、さらに観測誤差分散 \(\sigma_n^2\) を加えます。実装では逆行列を明示的に計算せず、通常は Cholesky 分解を使って連立方程式を解きます。[1]

学習ではカーネルの設定をデータに合わせる

カーネルの種類はモデル作成者が選び、長さ尺度や信号分散、観測誤差分散などのハイパーパラメータは、周辺尤度を最大化して推定する方法が一般的です。周辺尤度にはデータへの適合とモデルの複雑さの釣り合いが含まれます。[1]

ただし、得られる不確かさは選んだ平均関数、カーネル、誤差モデルが妥当であるという条件付きです。信頼区間の幅が狭くても、モデルの仮定が現象と合っていなければ、現実の不確かさを十分に表さない場合があります。

線形回帰との違い

線形回帰とガウス過程回帰の基本的な違い
観点 線形回帰 ガウス過程回帰
関数の形 説明変数の線形結合を基本とする カーネルが許す非線形な関数を表せる
推定対象 主に有限個の回帰係数 関数値の同時分布
不確かさ 仮定の下で平均応答や予測の区間を求める 各入力における予測分布を直接得る
計算負荷 比較的軽い 標準法はデータ数の増加に弱い

Pythonでの最小例

scikit-learn では、RBF カーネルと観測誤差を表す WhiteKernel を組み合わせて実装できます。return_std=True を指定すると、予測平均と標準偏差を得られます。[2]

import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import ConstantKernel, RBF, WhiteKernel

x_train = np.array([0.0, 1.0, 2.0, 3.0])[:, np.newaxis]
y_train = np.array([0.1, 0.9, 0.2, -0.8])

kernel = (
    ConstantKernel(1.0) * RBF(length_scale=1.0)
    + WhiteKernel(noise_level=0.1)
)
model = GaussianProcessRegressor(
    kernel=kernel,
    normalize_y=True,
    n_restarts_optimizer=5,
    random_state=0,
)
model.fit(x_train, y_train)

x_test = np.linspace(-1.0, 4.0, 200)[:, np.newaxis]
mean, std = model.predict(x_test, return_std=True)

lower = mean - 1.96 * std
upper = mean + 1.96 * std

lower と upper は、予測分布が正規分布であることに基づく点ごとの約 95% 区間です。この区間は、曲線全体を同時に 95% の確率で覆う同時区間とは異なります。

向いている場面と注意点

  • 向いている場面: データが少量から中規模で、非線形関係と予測の不確かさをともに知りたい場合。
  • 特に有用な用途: 実験計画、ベイズ最適化、空間補間、計算コストの高いシミュレーションの代理モデル。
  • カーネル選択: 滑らかさ、周期性、変化率など、対象についての知識をカーネルへ反映する必要があります。
  • 外挿: 観測範囲の外では平均関数やカーネルの仮定へ戻るため、データだけから遠方の傾向を保証する手法ではありません。
  • 大規模データ: 標準的な厳密計算は重いため、誘導点などを使う疎近似が必要になる場合があります。[1]

まとめ

ガウス過程回帰は、カーネルで関数の似かたを定め、観測後の関数の確率分布を計算する回帰手法です。予測曲線だけでなく、どこで予測に自信があり、どこで不確かかを示せる点が中心的な特徴です。実際に使うときは、予測平均の当てはまりとともに、カーネルの仮定、予測区間の妥当性、データ数に対する計算負荷を確認します。
