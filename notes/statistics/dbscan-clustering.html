DBSCANというクラスタリング手法とは？

作成日: 2026-10-28

カテゴリ: statistics

元の質問

DBSCANというクラスタリング手法とは？

回答

DBSCANは、点が十分に密集した領域を連結してクラスタにし、どの密集領域にも属さない点をノイズとして分けるクラスタリング手法です。クラスタ数を先に指定せず、細長い形や曲がった形のクラスタも見つけられます。名称は Density-Based Spatial Clustering of Applications with Noise の頭文字です。[1]

2つの設定値で「密集」を決める

DBSCANの中心となる設定は、近傍の半径 \(\varepsilon\) と、その近傍に必要な点の最小数 \(m\) です。実装では後者を min_samples と呼ぶことが多く、自分自身も個数に含めます。点 \(p\) の \(\varepsilon\) 近傍を、距離関数 \(d\) を使って式 (1) のように定めます。[1][2]

\[ N_{\varepsilon}(p) = \{q \mid d(p,q) \leq \varepsilon\} \tag{1} \]

この近傍に \(m\) 個以上の点があれば、\(p\) はコア点です。つまり式 (2) を満たす点が、クラスタを成長させる起点になります。

\[ \lvert N_{\varepsilon}(p) \rvert \geq m \tag{2} \]

コア点・境界点・ノイズ

  • コア点：自分の \(\varepsilon\) 近傍に \(m\) 個以上の点がある。
  • 境界点：自分だけではコア点の条件を満たさないが、あるコア点の近傍に入る。
  • ノイズ：コア点でも境界点でもない。scikit-learnではラベル -1 が付く。

アルゴリズムは、未処理のコア点を見つけると、その近傍の点を同じクラスタへ追加します。追加された点もコア点なら、さらにその近傍へ広げます。この連鎖が止まるまで探索するので、中心からの距離だけでは表しにくい形のクラスタもたどれます。[1]

k-means法との違い

DBSCANとk-means法の主な違い
観点DBSCANk-means法
事前に決めるもの近傍半径と最小点数クラスタ数
得意な形密度で連結できる複雑な形重心の周囲にまとまる形
外れた点ノイズとして残せるいずれかのクラスタに割り当てる

ただし、DBSCANがクラスタ数を自動で正しく推定する、と考えるのは正確ではありません。\(\varepsilon\) と \(m\) を変えれば、クラスタ数もノイズ点の数も変わります。

パラメータをどう考えるか

  • \(\varepsilon\) が小さすぎる：多くの点がノイズになり、1つのまとまりが細かく分断されやすい。
  • \(\varepsilon\) が大きすぎる：本来は別の密集領域が橋渡しされ、1つのクラスタになりやすい。
  • \(m\) を大きくする：より高い密度を満たす領域だけがクラスタとして残る。

さらに、距離に基づくため特徴量の単位と尺度が結果を左右します。例えば気温を数十という値、降水量を数百という値のままユークリッド距離へ入れると、数値範囲の大きい特徴量が距離を支配しやすくなります。標準化するか、研究上の意味に合う距離と重みを設計してから、複数の設定値で結果の安定性を確認します。

Pythonでの最小例

scikit-learnでは、eps が \(\varepsilon\)、min_samples が \(m\) に対応します。次の例では、近い2群にラベル 0 と 1 が付き、遠く離れた1点は -1、つまりノイズになります。[2]

import numpy as np
from sklearn.cluster import DBSCAN

points = np.array([
    [1.0, 2.0],
    [2.0, 2.0],
    [2.0, 3.0],
    [8.0, 7.0],
    [8.0, 8.0],
    [25.0, 80.0],
])

labels = DBSCAN(eps=3.0, min_samples=2).fit_predict(points)
print(labels)  # [ 0  0  0  1  1 -1]

向く場面と向かない場面

空間座標上の観測、移動軌跡、画像中の点群など、近さに意味があり、ノイズを含むデータに向きます。反対に、クラスタごとの密度が大きく異なるデータでは、1組の \(\varepsilon\) と \(m\) ですべてを捉えるのが難しくなります。また、高次元では近傍探索そのものが難しくなるため、距離尺度や次元削減を含めた検討が必要です。[3]

まとめ

DBSCANは「近い点を機械的に同数へ分ける」のではなく、一定半径内の点数で局所的な密度を定義し、密な領域をつないでいく手法です。クラスタ数が未知で、複雑な形とノイズを扱いたいときに有力ですが、距離の定義、特徴量の尺度、\(\varepsilon\) と \(m\) の感度確認が結果の解釈に欠かせません。
