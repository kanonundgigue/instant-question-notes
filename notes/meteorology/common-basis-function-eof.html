EOF解析に関連したCommon Basis Function（CBF）とは？

作成日: 2026-08-07

カテゴリ: meteorology

元の質問

EOF解析に関連した、CBFとは？ Common Basis Functionのことです。

回答

Common Basis Function（CBF）は、観測・再解析から得たEOFパターンを共通の基底として固定し、各気候モデルの偏差場をその基底へ射影して比較する方法です。通常のEOF解析をモデルごとに独立に行うと、観測EOF1に対応する変動がモデルEOF2やEOF3へ移ったり、複数モードへ分かれたり、EOFの符号が反転したりします。CBFは同じ観測基底を全モデルへ適用することで、このモード対応付けの曖昧さを避けます。[1]

何を計算しているか

観測偏差場から求めた対象モードのEOFを \(\boldsymbol{e}_{\mathrm{obs} }\)、モデルの時刻 \(t\) における偏差場を \(\boldsymbol{x}_{m}(t)\)、格子面積などの空間重みを行列 \(\mathbf{W}\) とします。正規化方法の細部を省いた模式的なCBF PCは、

\[ a_m(t) =\boldsymbol{x}_{m}(t)^{\mathsf{T} } \mathbf{W}\boldsymbol{e}_{\mathrm{obs} } \]

です。つまり、各時刻のモデル偏差が観測EOFとどれだけ同じ向きにあるかを内積で測った時系列です。実装ではEOFとデータの緯度重み・正規化規約を一致させます。

次に、CBF PCをモデルの各格子点の偏差へ回帰し、モデル内でその時系列とともに変動する空間パターンを得ます。格子点 \(j\) の回帰係数は、

\[ b_{m,j} =\frac{\operatorname{Cov}\!\left[x_{m,j}(t),a_m(t)\right] } {\operatorname{Var}\!\left[a_m(t)\right] } \]

と表せます。文献とPCMDI Metrics Packageでは、この「モデル偏差を観測EOFへ射影してCBF PCを作り、そのPCをモデル偏差へ回帰する」手順が採用されています。[2]

通常のEOF解析と何が違うか

方法 基底の決め方 主な用途
通常EOF 各データ自身から分散を最大化する基底を求める 各データに固有の主要変動を発見する
CBF 観測EOFを固定し、各モデルを同じ基底へ射影する 観測で定義したモードの再現性をモデル間で比較する
common EOF 複数データの共分散行列を同時に扱って共通基底を推定する 全データ群に共通する変動軸を推定する

したがって、CBFは「複数モデルを連結してもう一度EOF解析する方法」ではありません。また、common EOFは複数群から共通固有ベクトルを推定する別の方法であり、観測EOFを一方向に基準とするCBFとは区別が必要です。[3]

CBFを使う利点

  • mode swappingを避ける: 観測EOF1に似たモデル変動がEOF2やEOF3に現れても、固定した観測EOFへの射影で拾える。
  • mode splittingに強い: 観測の一つのモードが複数のモデルEOFへ分散していても、観測方向に沿う合成的な変動を評価できる。
  • 符号を統一できる: EOF固有の任意な符号反転に起因する比較の手間を減らせる。
  • 比較軸が共通になる: 空間パターン、CBF PCの標準偏差、説明分散、相関、RMSEなどを同じ観測定義のもとで比較できる。PCMDI Metrics PackageもCBFと通常EOFの両方を出力します。[4]

解釈上の注意

  1. モデル自身の最適EOFではない: CBFはモデル分散を最大化する方向を探していません。観測で定義した方向に限って、モデルがどの程度変動するかを問います。
  2. 観測基準に依存する: 観測EOFが解析期間、データセット、領域、季節に不安定なら、CBFもその不確実性を引き継ぎます。複数の再解析・観測データで感度を確認します。
  3. 前処理を一致させる: 変数、単位、格子、領域、欠測マスク、季節、気候値期間、トレンド処理、領域平均除去、緯度重みを揃えます。
  4. 高い一致は機構の正しさを保証しない: 観測EOFに似たパターンと振幅を再現しても、そのモデルが同じ力学過程で変動を作っているとは限りません。

使い分け

モデルが持つ主要変動を探索したいなら通常EOF、観測で定義したNAO・SAM・PDOなどの再現性を公平に比較したいならCBFが向いています。実務では両方を併記し、通常EOFでモデル固有のモード構造を確認しながら、CBFで観測モードに沿うパターンと振幅を評価するのが安全です。

まとめ

CBFは、観測EOFを「共通の物差し」として各モデルへ適用する評価法です。観測EOFをモデル場へ射影してCBF PCを作り、そのPCをモデル場へ回帰して対応パターンを得ます。モード番号の入れ替わりや分裂を避けられる一方、結果は選んだ観測EOFと前処理に依存するため、通常EOFや複数観測データとの併用が重要です。
